Join the Community

  1. 01

    Report bugs and flaws

    Found a bug, a result that does not match the original package, or a gap in the docs? Open an issue on that library's GitHub repository. If you are not sure which one, open it here.

    Open an issue ↗
  2. 02

    Collaborate on porting your packages and software

    If you develop a package and want it to reach users of another language, we can port it together. You keep full credit for the method, and the port is listed on this page as a community collaboration.

    Get in touch ↗
  3. 03

    Collaborate on porting classic, still-useful software to modern languages

    Many tools that people still rely on were written years ago and have become hard to keep running or build on. Tell us which one you depend on, or help us port it.
